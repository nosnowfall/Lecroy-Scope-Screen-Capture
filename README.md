# Lecroy-Scope-Screen-Capture
Script to automate screen captures from Teledyne LecCoy Oscilloscopes

A word of caution: the original script behaved well on LeCroy Wavesurfer 3024z and similar models, but fails at random on other versions of the wavesurfer platform. I do not know why and am too frustrated to figure it out so I bought a flash drive and a mouse for the scope instead.
