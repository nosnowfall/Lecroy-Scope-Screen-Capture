# Lecroy-Scope-Screen-Capture
Script to automate screen captures from Teledyne LecCoy Oscilloscopes

A word of caution: the original script behaves well with LeCroy Wavesurfer 3024z and similar models, but fails at random on other versions of the Wavesurfer platform. It is only stable for USB/VISA, not for TCP/IP (this seems common to all VISA applications I have used). I do not know why and am too frustrated to figure it out so I recommend you buy a flash drive and a mouse for the scope instead. If you do that, get an 8GB FAT32 drive, because some older models don't support large volumes or modern filesystems.
